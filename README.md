# Caelus

a self operating drone system designed to handle its entire mission lifecycle without human input, from takeoff to task execution to automated docking and charging.

## Status

(3/18) Final Build In Progress. Software Team built out. One month from Pre-Release Demo.

## Mission Objective

Build an autonomous drone that can:

* Launch from a docking station
* Perform a predefined task
* Return to the dock
* Land on a charging pad for recharging
